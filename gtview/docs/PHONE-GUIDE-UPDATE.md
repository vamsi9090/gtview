# Phone installation redesign

The supplied phone is the imaging device, with its rear camera facing the road from the approved dashboard holder. This revision supersedes earlier installation illustrations and the nine legacy device confirmations.

- Four focused stages: position, secure, align, power. Each has one manual confirmation and one forward action.
- New original concept photography shows a person seating the phone and the phone kit. Photographs are not approved mounting diagrams.
- An interactive learning preview compares clear, tilted, blocked and loose examples. A keyboard-accessible horizon slider demonstrates tilt. It never accesses a camera or reports a real measurement; stability cannot be diagnosed from a preview.
- Current installation stage resumes on the same browser. Existing records remain readable, while legacy device checks do not count as phone installation checks.
- Review links, kit labels, preparation imagery and installation completion gates now use the phone flow.
- The save action is functional; responsive layouts stack the illustration, instructions and controls on small screens. No autoplay is required.

Hardware placement, angle tolerances, cure time, power requirements, activation, official submission and reward verification still require approved program information or integrations. Existing local photo records and support drafts are preserved. Public access and the first GTview site are unchanged.
